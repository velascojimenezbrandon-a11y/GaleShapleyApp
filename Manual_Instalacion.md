Manual de instalación y configuración

GaleShapleyApp

1. Descripción

GaleShapleyApp es una aplicación Android desarrollada en Kotlin y Jetpack Compose que permite ejecutar y visualizar el algoritmo de emparejamiento estable de Gale-Shapley.

2. Requisitos

Para utilizar la aplicación:

* Dispositivo Android compatible.
* Archivo APK de GaleShapleyApp.

Para ejecutar el código fuente:

* Android Studio.
* Android SDK.
* Dispositivo Android o emulador.

3. Instalación mediante APK

1. Descargar el archivo APK de GaleShapleyApp.
2. Abrir el archivo en un dispositivo Android.
3. Permitir la instalación desde esa fuente si el sistema lo solicita.
4. Presionar Instalar.
5. Abrir la aplicación.

4. Instalación desde Android Studio

1. Descargar el proyecto desde GitHub mediante Code → Download ZIP.
2. Descomprimir el archivo.
3. Abrir Android Studio y seleccionar Open.
4. Seleccionar la carpeta del proyecto.
5. Esperar a que finalice la sincronización de Gradle y configurar el SDK si se solicita.
6. Conectar un dispositivo Android o iniciar un emulador.
7. Presionar Run para ejecutar la aplicación.

5. Uso de la aplicación

1. Seleccionar entre 2 y 6 participantes por conjunto.
2. Elegir el conjunto proponente (A o B).
3. Generar las listas de preferencias.
4. Modificar las preferencias manualmente si se desea.
5. Ejecutar el algoritmo.
6. Visualizar el emparejamiento estable, el grafo y la bitácora de propuestas.

6. Tecnologías utilizadas

* Kotlin.
* Jetpack Compose.
* Android Studio.
* Gradle.
