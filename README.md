GaleShapleyApp

Aplicación Android desarrollada en Kotlin y Jetpack Compose para implementar y visualizar el algoritmo de emparejamiento estable de Gale-Shapley.

Funcionalidades:

* Configuración de 2 a 6 participantes por conjunto.
* Selección del conjunto proponente (A o B).
* Generación de preferencias aleatorias.
* Modificación manual de las preferencias.
* Ejecución del algoritmo de Gale-Shapley.
* Visualización del emparejamiento mediante un grafo bipartito.
* Registro de propuestas, aceptaciones y rechazos.

Tecnologías utilizadas:

* Kotlin
* Android Studio
* Jetpack Compose
* Gradle
